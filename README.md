## 工业异常检测

| 论文                                                                                                     | 核心方法/框架                                                     | 任务设定                                               | 关键创新                                                                                                                                                                                | 性能/结果                                                                           |
| -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| **Unification of Closed-Open Industrial Detection Scenarios**<br>https://www.alphaxiv.org/abs/2606.07953 | RTVPNet（Refined Text-Visual Prompt Network）                     | 封闭集 + 开放词汇工业检测                              | ①提出MMIOC-1M大规模多模态工业基准（超100万样本，14个超类，29个工业场景，351个缺陷子类）；<br>②专家辅助领域投影机制；<br>③基于能量的稀疏采样自动生成视觉提示；<br>④双向文本-视觉交互模块 | MMIOC-1M、LVIS、COCO上SOTA                                                          |
| **SwinAD**<br>https://www.alphaxiv.org/abs/2607.14534                                                    | 基于重建的多类别无监督异常检测框架                                | 无监督（无异常标签）                                   | ①冻结预训练Swin Transformer V2编码器 + 特征多样性保持重建解码器；<br>②层级编码器提供语义丰富的多尺度特征；<br>③多阶段瓶颈模块+dropout防止平凡恒等映射；<br>④多分支重建假设互补          | MVTec AD、VisA、Real-IAD上图像级性能竞争力强，像素级定位精度显著提升                |
| **DriftAD**<br>https://www.alphaxiv.org/abs/2608.23723                                                   | Visually-Guided Text Drift（视觉引导文本漂移）                    | 少样本工业异常检测（FSAD）                             | ①异常信号放大模块（ASA）：空间+频率分支增强微弱缺陷信号；<br>②VGTD动态变换冻结的CLIP文本嵌入，逐层引导文本特征；<br>③摒弃静态prompt，实现文本动态“漂移”                                 | ACM Multimedia 2026录用                                                             |
| **ADOPD**<br>https://www.alphaxiv.org/abs/2608.09789                                                     | Reference-Privileged On-Policy Distillation（参考特权同策略蒸馏） | MLLM-based零样本/少样本工业异常检测                    | ①训练时教师可访问参考图像，学生仅看查询图像；<br>②同策略蒸馏：教师评估学生生成的rollout；<br>③匹配/不匹配参考下的对数比率定义学习方向；<br>④似然差距校准序列级权重                      | MMAD基准零样本77.31%平均准确率，较Qwen3-VL-4B提升6.14个百分点，超单样本2.64个百分点 |
| **GenAU**<br>https://www.alphaxiv.org/abs/2607.01049                                                     | Generalist视觉语言框架（指令跟随模型）                            | 零样本图像级检测、像素级分割、多类型异常检测、缺陷分析 | ①统一图像级检测、像素级分割、多类型异常检测和缺陷分析于单一指令跟随模型；<br>②引入[SEG_defect]和[SEG_normal]两个分割token，其隐藏状态作为语言引导查询；<br>③语言引导的缺陷分析          | VisA零样本多类型异常检测F1达29.0%，MPDD达69.8%                                      |
| **O-VAD**<br>https://www.alphaxiv.org/abs/2607.18142                                                     | 训练无关的Agentic框架（以对象为中心的跟踪+时间状态推理）          | 工业视频异常检测（IVAD）                               | ①无需训练、无需领域特定知识；<br>②跟踪检测对象随时间的时空动态和潜在变换；<br>③在对象级时间状态轨迹上进行推理；<br>④输出可解释的异常过程和类型报告                                      | 三个IVAD数据集上优于前沿VLM、Agentic框架及传统VAD方法                               |
